よくある質問

表示言語や単位(kg/lb)は変えられますか?

「設定」タブから、表示言語(日本語 / English)と重量の単位(kg / lb)をそれぞれ切り替えられます。2つは独立した設定なので、日本語表示のままlbを使う、英語表示でkgを使う、といった組み合わせもできます。初回起動時は端末の言語設定に従います。

記録は常にkgで保存されており、単位を切り替えても過去の記録が書き換わることはありません。表示と入力の単位だけが変わります。

データはどこに保存されますか?通信は発生しますか?

トレーニング記録は端末内にのみ保存されます(iOS版はSQLite、Web版はブラウザのlocalStorage)。アカウント登録・ログインは不要で、記録・集計・グラフ・バックアップなどの主要機能はすべてオフラインで動作します。種目のやり方をYouTubeで調べる任意の機能を使ったときだけ、外部ブラウザでYouTube検索結果を開きます(その際に送信するのは種目名だけで、トレーニング記録が送信されることはありません)。詳しくはプライバシーポリシーをご覧ください。

機種変更したら記録は引き継がれますか?

自動では引き継がれません。記録は端末内保存のため、機種変更やアプリの再インストールの前に、必ず「設定」タブから「バックアップを書き出す」でJSONファイルを保存してください。新しい端末でアプリを開き、「設定」→「バックアップから復元する」で保存したJSONファイルを選択すると復元できます。

バックアップの書き出し方法

  1. 「設定」タブを開く
  2. 「バックアップを書き出す」をタップ
  3. JSON形式のファイルが書き出されます(ファイル名は kurabell-backup-日付.json)。iCloud DriveやAirDrop、メールなど、お好きな方法で保存・転送してください

あわせてCSV形式での書き出しにも対応しています(Excel等の表計算ソフトで開けます)。CSVは記録の閲覧・集計用で、CSVからの復元(読み込み)はできません。復元にはJSON形式のバックアップをお使いください。

JSONバックアップからの復元方法

  1. 「設定」タブを開く
  2. 「バックアップから復元する」をタップし、保存しておいたJSONファイルを選択
  3. 内容を確認するダイアログが出るので、よろしければ「OK」を選択

復元を行う前に、現在のデータは自動的に退避されます。万一、復元した内容に問題があった場合は、「設定」タブから復元前の状態に戻すことができます。壊れたファイルや対応していない形式のバックアップを選んだ場合は復元されず、現在のデータはそのまま残ります。

アプリを削除(アンインストール)するとどうなりますか?

アプリを削除すると、端末に保存されているすべての記録が失われます。削除の前に、必ず「設定」タブから「バックアップを書き出す」を行ってください。書き出したJSONファイルを別の場所(iCloud Driveなど)に保管しておけば、再インストール後に復元できます。

記録を削除したい(一部・全部)

個別の記録は「履歴」タブから対象の記録を選び、削除できます。すべての記録をまとめて削除したい場合は、「設定」タブの「すべての履歴を削除」から行えます(確認ダイアログが表示されます)。この操作は元に戻せないため、必要であれば先にバックアップを書き出してください。

広告や課金はありますか?

広告やトラッキングはありません。課金方針(有料/無料)についてはApp Store上の表示をご確認ください。

KURABELL Workout Log is a strength training log that shows you last session's weight, reps and RIR set by set while you record. This page covers how to reach us and the questions we get most often.

Frequently asked questions

Can I change the language or the weight unit (kg/lb)?

Yes — the Settings tab has separate switches for display language (日本語 / English) and weight unit (kg / lb). They are independent, so you can use English with kg, or Japanese with lb, whichever you prefer. On first launch both follow your device settings.

Your records are always stored in kilograms. Switching the unit changes only display and input — it never rewrites your past workouts.

Where is my data stored? Does the app use the network?

Your training records are stored only on your device (SQLite on iOS, browser local storage on the web). There is no account and no sign-in, and logging, totals, charts and backups all work offline. The only time the app reaches the network is when you choose to look up an exercise on YouTube, which opens the search results in your browser — and only the exercise name is sent, never your records. See the privacy policy for details.

Will my records transfer to a new phone?

Not automatically. Because records live on the device, export a backup before you switch phones or reinstall: Settings tab → "Export backup". On the new device, open the app and use Settings → "Restore from backup" to select the JSON file you saved.

How do I export a backup?

  1. Open the Settings tab
  2. Tap "Export backup"
  3. A JSON file is written out (named kurabell-backup-DATE.json). Save or send it however you like — iCloud Drive, AirDrop, email

CSV export is also available for opening your log in Excel or another spreadsheet. CSV is for viewing and analysis only — you cannot restore from it. Use the JSON backup to restore.

How do I restore from a JSON backup?

  1. Open the Settings tab
  2. Tap "Restore from backup" and select the JSON file you saved
  3. Confirm the dialog that appears

Your current data is set aside automatically before a restore, so if something looks wrong afterwards you can roll it back from the Settings tab. If you pick a corrupted or unsupported file, nothing is restored and your current data is left untouched.

What happens if I delete the app?

Deleting the app removes every record stored on the device. Always export a backup from the Settings tab first. If you keep the JSON file somewhere else (iCloud Drive, for example), you can restore it after reinstalling.

How do I delete records — one workout, or everything?

To delete a single workout, open the History tab, select it and delete it there. To remove everything at once, use "Delete all history" in the Settings tab (a confirmation dialog appears). This cannot be undone, so export a backup first if you might want the data later.

Are there ads or in-app purchases?

There are no ads and no tracking. For pricing, please check the App Store listing.
