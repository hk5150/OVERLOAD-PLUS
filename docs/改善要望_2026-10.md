## 2. お任せボタン(最初の種目設定のときだけ)

- 分割タブの各 Day で、**登録種目が0件のときだけ**「おまかせで入れる」を出す。押すと、その Day の部位に合う定番の種目を登録する。登録後はボタンを出さない
- 1つの Day が4〜5種目になるよう、部位ごとの優先順の上から取る(部位が少ない Day ほど1部位から多く取る)。バーベル中心でよい(北村さん確認)

| 部位 | 優先順 |
|---|---|
| 大胸筋 | バーベルベンチプレス → インクラインダンベルプレス → ケーブルフライ |
| 広背筋 | ラットプルダウン → ケーブルシーテッドロウ → ワンハンドダンベルロウ |
| 僧帽筋 | ダンベルシュラッグ |
| 三角筋 前部 / 中部 / 後部 | ダンベルショルダープレス / サイドレイズ / フェイスプル |
| 上腕二頭筋 / 三頭筋 | ダンベルカール / トライセッププレスダウン |
| 大腿四頭筋 | バーベルスクワット → レッグプレス → レッグエクステンション |
| ハムストリングス / 臀部 | ルーマニアンデッドリフト / ヒップスラスト |
| ふくらはぎ | スタンディングカーフレイズ |
| 全身(全身法) | バーベルスクワット・バーベルベンチプレス・デッドリフト・ラットプルダウン・ダンベルショルダープレス |

- 並べて「AIに相談して決める」も出す。0件の Day から押したときは依頼文を「この日の部位に合う種目を4〜5個、順番つきで提案して」に変え、**その部位のアプリ内の種目名の一覧を渡して、その中から選ばせる**(AI がアプリに無い名前を返さないように)。登録済みの Day は今までどおり「見直し」の依頼文(`share.dayPrompt`)
- 種目名は `EXERCISE_DB` の正式名で持つこと(別名だと前回の記録と名前が一致しなくなる)

## 3. Day の追加と種目の追加

- **a.** Day を追加したら、まず部位のチップ。部位を選ぶと「おまかせで入れる」「AIに相談して決める」を出す。Day 名は部位から自動で付ける(例: 大胸筋+三角筋前部 →「胸・肩」)。手で変えられる
- **b.** 種目一覧の 240px の枠(`maxHeight: 240`)をやめ、画面全体でスクロール。部位ごとに見出しで区切り、最近使った種目は各見出しの先頭
- **c.** 登録済みの種目をチップから縦の一覧にして ▲▼ と ✕。この順が今日のメニューの並び
- **d.** 記録中に足した種目は、今は黙って今日の Day に登録している(`addExercise` 内、Day に登録種目が1つ以上あるときだけ)。登録したときに「Day『Push』にも登録しました(取り消す)」を出す。登録種目0件の Day で保存したら「この内容を Day『Push』の種目として登録しますか?」と聞く(分割なしのときの `offerSaveAsMenu` と同じ形)
- **e.** Day の編集中に「この後ろに Day を追加」。一番下の「＋ Dayを追加」は残す

## 4. Watch の休憩の知らせ

- **a.** 休憩画面を開いている間は、1・2・3分(c で選んだ時間)の切り替わりで Watch 自身が強めの振動を鳴らす(通知とは別に)
- **b.** Watch がワークアウトを記録している間は、iPhone で始めた休憩も Watch が通知を予約する。手首に二重に届かないよう、その間は iPhone の通知を止める(v134 の Live Activity の抑止と同じ考え方。`watchLiveFor`)
- **c.** iPhone の設定に「休憩の通知」。1:00・1:30・2:00・2:30・3:00・4:00・5:00 から複数選択、初期値は今と同じ 1・2・3分(`restNotifyMinutes`)。選んだ時間はスナップショットで Watch にも送る

## 5. Watch の −/+ の長押し

- 押してすぐは今までどおり1回分(`StepPad` の触れた瞬間の反応は変えない)
- 押したまま0.4秒で連続(1秒に約8回)。1.5秒を過ぎると重量は 5kg(lb は 10)刻みに加速、回数は1のまま
- 連続中の振動は大きく変わったときだけ(10kg ごとなど)。離したらすぐ止まる
- Digital Crown は使わない(2026-09-26 の判断のまま)

## 6. 各セットに 1RM

- 各セットの下の行(「前回 70×9 RIR1」の行)の右端に `1RM 92.5`。重量と回数が入っていれば出し、RIR が入るまでは薄く
- 自己ベストを超えたセットは数字を緑に
- ウォームアップ・補助ありには出さない。**13回以上のセットにも出さない**(Epley 式が高めに出るため。北村さん判断)
- ダンベルは両手分、自重は体重込み(比較の行と同じ基準。`est1RM` / `effWeight`)

## 8・9. ボリュームの表記と Watch のリング

- 基準は今と同じ `compareBase`(同じ Day の直近最大3回の平均。同じ Day の記録が無ければ Day を問わず直近3回)
- 表記: 同じ Day が2〜3回 →「過去N回平均まで あと480kg」、1回 →「前回まで あと480kg」、Day を問わない →「直近N回平均まで…」。超えたら「過去3回平均 +105kg」。**「平均」だけの表記はしない**(北村さん「平均というのが分かりにくい」)
- iPhone: ゲージの右端の「あと480」「+105」を上の表記に(単位つき)。入りきらない幅では2行に
- Watch: iPhone から今のボリューム・基準・表記を送る(計算は iPhone)。**リング**(基準で1周、超えたら緑)と上の表記を、**種目一覧の上と休憩画面の両方**に出す

## 10. YouTube でのフォーム確認を売りに

- **a.** 種目名の行に「▶ フォーム」を常に出す(11 と合わせて)
- **b.** 「初回」のバッジの種目に「フォームを動画で確認」を1行
- **c.** 検索語を「{種目名} やり方 フォーム」→「{種目名} フォーム コツ」(`youtube.query`。英語も合わせて見直す)
- **d.** 説明文に1節(例「■ フォームは動画ですぐ確認」)
- **e.** スクリーンショットに1枚(見出し例「フォームの確認も、ワンタップで」)
- **f.** キーワードに「フォーム」を足す(`APPSTORE.md` の「次のバージョンで差し替えるキーワード」の72文字+5=77文字。1.1 で77文字は入った)
- アプリ内に YouTube を埋め込むことはしない(外部通信を足さない方針)。外部で開くまま

## 11. 種目カードの操作

- 「⋯」をやめ、全部外に出す
- **削除(✕)は別枠**: 種目名の行の右端に、ほかの操作から離して置く。セットに入力がある種目だけ確認を出し、消した直後に「元に戻す」を数秒(北村さん「削除は結構使う」)
- 残り7つ(▲▼・設定・フォーム・AI・変更・履歴・スーパーセット)は、比較の行のすぐ下にアイコン+短い文字で1行。▲▼とスーパーセットは薄い色
- 1.2 で畳んだ理由(2段のボタンでカードが長くなり、入力欄が下に追いやられた)に配慮して、1段に抑える。`docs/画面改善.md`

## 12. 保存したら Watch に「お疲れ様でした」

- 保存の知らせ(スナップショットの `lastSaved`)が届いたら完了画面と成功の振動
- 中身: 時間、種目数・セット数、ボリューム(過去3回平均との比較、超えたら緑)、1RM を更新した種目、心拍の平均と消費カロリー(Watch がワークアウトを記録していたときだけ、Watch 自身の値)。時間・ボリューム・更新種目は iPhone が保存時に計算して送る
- タップか15秒で待機の画面へ
- Watch がワークアウトを記録していなかったときは、次に Watch アプリを開いたときに一度だけ出す
