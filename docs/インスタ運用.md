### 残っている手順

1. **北村さんがトークンを発行して `~/Insta/.env` に4行貼る**(私はトークンを扱わない)。
   Meta Developer → insta-agent のアプリ → Instagram → API setup with Instagram business login → 各アカウントで Add account → Generate token。
   権限: `instagram_business_basic` / `instagram_business_content_publish` / `instagram_business_manage_insights`
   ```
   IG_TOKEN_KURABELL_JP= / IG_ID_KURABELL_JP= / IG_TOKEN_KURABELL_EN= / IG_ID_KURABELL_EN=
   ```
2. トークンの確認(読むだけ): `GET https://graph.instagram.com/v21.0/me?fields=username&access_token=...` で2アカウントとも名前が返るか
3. `cd ~/Insta && .venv/bin/python kurabell/autopost.py --account jp --dry-run` を見せる
4. **北村さんの前で** `--account jp --force` で1本目を本番投稿。投稿URL・AIラベル・音声・`投稿済み/` への移動・`kurabell/state/ledger.json` を確認
5. `kurabell/launchd/*.plist` を `~/Library/LaunchAgents/` にコピーして `launchctl load`。
   `launchctl kickstart -k gui/$UID/com.kurabell.autopost.jp` で一度起こし、ログに「間隔内なので何もしない」が出ることと、
   launchd から iCloud Drive を読めること(macOS のファイルアクセス許可)を確かめる
6. 英語版も同様に1本目を確かめる(`--account en --force`)
