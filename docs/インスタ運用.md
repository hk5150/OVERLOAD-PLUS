### launchd と iCloud Drive(解決済み、2026-10-08)

選択肢は A(Xcode 同梱 Python にフルディスクアクセス)と B(予約を iCloud の外へ)。**B を選んだ**。
A はその Python で動く全スクリプトにメール・写真まで読める権限が及び、Xcode の更新で黙って外れうる。
B で失うのは「iPhone から予約に足せる」ことだけで、リールは Mac で作って置いているので実害がない。

- `accounts.yaml` の `icloud_root` を `media_root` に改名し、`~/Insta/kurabell/reels` に向けた(git 管理外)
- 移した後、使い捨てジョブで launchd から `--dry-run` が予約を読めることを確認
- Obsidian のノート(`obsidian_instagram_metrics`)は iCloud のまま。launchd からは **フォルダの一覧は拒否されるが、
  決まったファイルの作成・読み書きは通る**ことを確認した。insights はその1ファイルだけ書くので動く。
  確認のついでに、ノートは見出しだけの状態で作成済み
- 止まったときの `要確認.txt` も `reels/` に移った。iPhone からは見えないので、気づくきっかけは macOS の通知
