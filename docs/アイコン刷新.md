# アイコン刷新(1.2 で差し替え予定)

2026-10-01 に決定。**ブランチ `ui-refresh` で差し替え済み**(main にはまだ入っていない。画面改善と一緒に 1.2 で出す。`docs/画面改善.md`)。
Web 用の4枚(512 / 192 / 180 / maskable)は Service Worker が版ごとに取り直すので、256色に減色して約495KB → 約300KBにした。1024 は元のまま。

## 決まったもの

**オーバーロードのプレート**: 斜めから見た赤いウェイトプレートに、磨き仕上げのバーベルの軸。プレートの縁が1周を超えて
自分の始点に重なり、「前回を超える」を表す。背景はほぼ均一な黒鉛色。

- 生成: Genspark の GPT Image 2(`gsk img -m gpt-image-2`)。比較した候補(約30案)と経緯は
  claude.ai の比較ページ「KURABELL アイコン候補」(非公開)にある
- 書き出し一式: `~/Desktop/KURABELL-icon-N1d4/`(元画像 `source-1536.png` もここ)。**リポジトリには入れていない**

### 選んだ理由 / 見送ったもの
- 現行のダンベルは、29pt で板2本の線になり、競合(ダンベル・バーベルの図柄が多い)と並ぶと埋もれる
- 円形のリング(N1a)は洗練されていたが「筋トレのイメージが湧かない」(北村さん)。バーベルの軸を足して道具だと分かるようにした
- 持ち手の穴(トライグリップ)を開けた案は、穴の配置が笑った顔に見えたので見送り
- 正面寄りの角度は、短い軸がスイッチや電源ボタンに見えたので見送り
