### 作り直すとき

制作フォルダは `~/Desktop/KURABELL-reels/youtube-long/`。`marketing/youtube-long/` の `build.sh`・`shoot.sh`・`slides.html`・`tts.tsv` はその写し。

1. 音声: `tts.tsv` を1行ずつ `marketing/tools/tts.sh` に渡す。動画に入れる前に `gsk transcribe` で読み間違いを見る
2. 画面: シミュレータで録画する(`xcrun simctl io <端末> recordVideo`)。今回は撮影専用に iPhone 17 を使い、他のセッションの端末は使っていない
3. `shoot.sh` → `build.sh <出力.mp4>`

踏みやすいところ:

- **ダミー記録は `simctl spawn defaults write` では入らない。** アプリの領域に入らないので、`get_app_container … data` の `Library/Preferences/<バンドルID>.plist` に `CapacitorStorage.workout-log-v1` を plist で書く(初回起動の前に。旧 Preferences → SQLite の移行で取り込まれる)。中身は `seed.js` の出力
- **端末の操作は `demo-driver.js` で行った。** シミュレータの操作ツールは端末ごとに本人の承認が要り、不在だと止まる。そこでビルド済みの `App.app/public/` に `demo-driver.js` を置き、`index.html` の `app.bundle.js` の次で読ませた(生成物だけの変更で、リポジトリのアプリ本体は変えていない)。キーボードは出ず、タップの位置は丸で表示する
- **録画は画面が変わったときしかコマが出ない。** `fps=30` で固定してから切る。切り出し秒は録り直すたびに変わるので、`select='gt(scene,0.04)',showinfo` で時刻を調べて `build.sh` の表を直す
