# UI レビュー(2026-11-07、最初の部位の選び方を中心に)

北村さん「アプリの UI(特に最初の部位の選び方)に難がある。ユーザーが使いやすい UI を目指してレビューしてほしい」。
初回の状態から、iPhone 17 Pro シミュレータ(iOS 26.5、main `ab6686a` の画面)と Web 版(402×874)で、
ガイド → 分割タブ → 部位・種目の選択 → セット入力までを通した。影響の大きい順に並べる。

## 見立て

部位を選ぶ場面は3つある(記録タブの種目一覧の上、分割タブの Day 編集、カスタム種目の追加)。どれも
**解剖学名の17部位を、まとまりなしで1段に並べている**。トレーニングに慣れた人には正確だが、
初めての人は「胸」「背中」「肩」「脚」で考えるので、「広背筋? 僧帽筋? 脊柱起立筋?」で止まる。
さらに初回の画面は、いちばん迷う道(白紙の記録タブで部位から種目を探す)を主役のボタンにしている。

## 問題点と改善案(影響の大きい順)

### 1. 初回の主役ボタンが、いちばん迷う道へ送っている
- 今: ガイドを閉じると分割タブ。黄色の主役は「今すぐ記録する」で、押すと白紙の記録タブ(種目の検索欄+部位チップ+全種目の一覧)。
  分割の型(全身法・上下・PPL・5分割)は「または、分割メニューを設定する」として脇に置かれている
- 実際は、型を選ぶ方が早い。PPL を選んで「3日分をまとめておまかせで入れる」を押せば、2タップで「今日のメニュー」(5種目・初回3セット)が出て、
  「この内容で記録を開始」で始められる。部位も種目も選ばずに済む
- 案: 初回は「週に何回トレーニングしますか?」を主役にする(週1〜2回 → 全身法、週2〜4回 → 上半身/下半身、週3〜6回 → PPL、週5回以上 → 5分割)。
  選んだら定番の種目まで入れて、記録タブの「今日のメニュー」を開く。「今すぐ記録する」は下に小さく残す(自分で種目を選びたい人向け)

### 2. 型を選んだ後に、もう1回「おまかせ」を押さないとメニューが空
- 今: 型を選んだだけでは各 Day の種目が0件。記録タブを開くと「今日のメニュー」が無く、白紙の種目一覧に戻る(`w08`)。
  「3日分をまとめておまかせで入れる」を押すことに気づけないと、型を選んだ意味が無い
- 案: 型を選んだら、その場で定番の種目を入れる(`fillAllDayStarters` を `applyPreset` から呼ぶ)。分割タブで種目は ✕ で外せるので、確認は要らない。
  「AIに相談して決める」は各 Day に残す

### 3. 部位チップが解剖学名の17個で、記録タブでは横スクロールの1列
- 今: 記録タブは「すべて / 大胸筋 / 広背筋 / 僧帽筋 / 脊柱起立筋 / 三角筋前部 / 中部 / 後部 / 上腕二頭筋 / 三頭筋 / 前腕 / 大腿四頭筋 / ハムストリングス / 臀部 / 内転筋 / ふくらはぎ / 腹筋」を横1列。
  画面に見えるのは4つ半で、残りは指で送らないと分からない。肩だけで3つ、脚だけで5つある
- 案: 大きなまとまり8つ(**胸・背中・肩・腕・脚・お尻・お腹・全身**)を折り返して2行で全部見せる。押すと、その下の種目一覧を細かい部位の見出し
  (例: 肩 → 前部・中部・後部)で区切って出す。分割タブの Day 編集も同じ8つにして、細かい部位は「細かく選ぶ」を開いたときだけ。
  保存データの部位名(`MUSCLES`)は変えない。表示のまとめ方だけ変えるので、集計・記録・Watch には影響しない
  (英語は Chest / Back / Shoulders / Arms / Legs / Glutes / Abs / Full body)

### 4. 型のカードに「誰向けか」が無い
- 今: 「全身法 / 全身」「Push / Pull / Legs / Push → Pull → Legs」だけ。初めての人は PPL が何か、自分がどれを選べばいいか分からない
- 案: 各カードに1行(「週1〜2回。毎回全身を少しずつ」「週3回〜。押す日・引く日・脚の日」など)。1 の「週に何回」の問いと同じ言葉にする

### 5. 記録タブの種目一覧が、240px の枠の中でスクロールする
- 今: 画面のスクロールと枠のスクロールが二重。分割タブ側は 1.3 で解消した(改善要望 3b)が、記録タブは残っている。
  シミュレータでも、枠の中を送ろうとして画面が動く・その逆が起きやすい
- 案: 分割タブと同じく、枠をやめて画面ごとスクロール。部位を選んだときは見出しで区切る(3 と一緒に)

### 6. 種目を1つ押すと、すぐ記録が始まる
- 今: 一覧の種目を押した瞬間に経過タイマーが動き、上部バー(経過・ボリューム・インターバル開始)が出る。眺めるつもりで押しても始まる
- 案: 初回だけ「この種目で記録を始めます」と分かる表示にする、または「記録を開始」を押すまでタイマーを止めておく。影響は小さいので後回しでよい

### 7. カスタム分割で部位を選ぶと、種目の一覧がとても長くなる
- 今: 大胸筋+三角筋前部を選ぶと、22種目が全部並び、画面が約2画面分伸びる(`w02`)。おまかせ/AI のボタンが上にあるのは良い
- 案: 部位ごとに定番の5つ+「すべて表示」。3 の「大きなまとまり」と合わせると、選ぶ数がさらに減る

## そのままでよいと判断したもの
