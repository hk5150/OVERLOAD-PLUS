# 画面改善(1.2、ブランチ `ui-refresh`)

2026-10-01 に、北村さんが承認した改善案(12項目+各画面の細かい改善)を全部反映した。機能は変えていない。
案は claude.ai の「KURABELL 画面改善案」(非公開)。アイコンの刷新(`docs/アイコン刷新.md`)も同じブランチに入れた。

## 方針

- **色に役割を1つずつ**: 赤=主要操作と削除、黄=余力(RIR)・インターバル・注意、緑=前回を超えた印、
  青=スーパーセットと「補助あり」の印だけ。選択中のチップ・設定の切り替えは白地に黒文字(`chip()` の既定)。
  役割は `index.html` の `const C` にコメントで書いてある。新しく色を足すときはこれに従う
- **毎回出るものは小さく**: 注意書き・警告は、使い始め(保存した記録3回未満)か、該当したときだけ
- **記号は自前の線画**: 絵文字は使わない。`Icon` 部品(`ICON_PATHS`)に足す。共有用のプレーンテキスト(📌 など)は対象外

  取り込むときに、main 側で版(CACHE / APP_VERSION)が先に進んでいたら合わせて上げ直す
- iOS は `MARKETING_VERSION` を 1.2 にしてから TestFlight へ。実機で、⋯ のメニュー・カレンダーの色・Watch の入力画面を確認
- ~~App Store のスクリーンショットと説明文の「YOU WIN!」~~ → 2026-10-01 に対応済み。スクリーンショットは

## レビューで直したこと(2026-10-01)
- セット行の差分は、画面に出ている数字どうしで取る(lb で kg の前回と比べたときに「+0lb」が出ていた)。加重を外して0にしたときも重量の差を出す。補助ありと補助なしは比べない
- タブバーはアイコンを足しても高さ 56px ちょうどに固定(インターバルのパネルなどが 56px を前提にしている)
- 「⋯」から開く履歴・種目設定のパネルに、閉じるボタンを付けた
- 「書き出す ›」「購入 ›」は設定タブの該当の欄までスクロールする。設定タブではバックアップの帯を出さない
- Watch の前回の重量に、補助ありの印(補)を付ける(Labels に assisted を足した。iPhone は以前から送っていた)
