# 画面改善(1.2、ブランチ `ui-refresh`)

2026-10-01 に、北村さんが承認した改善案(12項目+各画面の細かい改善)を全部反映した。機能は変えていない。
案は claude.ai の「KURABELL 画面改善案」(非公開)。アイコンの刷新(`docs/アイコン刷新.md`)も同じブランチに入れた。

## 方針

- **色に役割を1つずつ**: 赤=主要操作と削除、黄=余力(RIR)・インターバル・注意、緑=前回を超えた印、
  青=スーパーセットと「補助あり」の印だけ。選択中のチップ・設定の切り替えは白地に黒文字(`chip()` の既定)。
  役割は `index.html` の `const C` にコメントで書いてある。新しく色を足すときはこれに従う
- **毎回出るものは小さく**: 注意書き・警告は、使い始め(保存した記録3回未満)か、該当したときだけ
- **記号は自前の線画**: 絵文字は使わない。`Icon` 部品(`ICON_PATHS`)に足す。共有用のプレーンテキスト(📌 など)は対象外

# 最初の部位の選び方(2026-11-07、ブランチ `claude/project-thread-uphuhb`)

北村さん「アプリの UI に難がある。特に最初の部位の選び方」。レビューは `docs/UIレビュー_2026-11.md`。
上位4つを「はい」で承認(2026-11-07)。

## 決めたこと
- **初回の分割タブは「週に何回トレーニングしますか?」**。型のカードは「週1〜2回 全身法 / 毎回、全身を少しずつ」のように、頻度を見出しにして説明を1行。
  選ぶと各 Day に定番の種目が入り、記録タブの「今日のメニュー」へ移る(1タップで「この内容で記録を開始」まで)。
  「今すぐ記録する」(黄色の主役)は、「分割を作らずに、種目を選んで記録する ›」の文字ボタンに下げた。
  「変更 / 作り直す」から型を選んだときは今までどおり分割タブに残る
- **型を選んだら、その場で定番の種目を入れる**(`applyPreset` が `starterPicks` を呼ぶ)。以前は0件のままで、
  「N日分をまとめておまかせで入れる」を押さないとメニューが空だった。種目は分割タブの ✕ で外せるので確認は出さない。
  **ただし、その Day の部位に合う種目を記録したことがある場合は入れない**(登録0件の Day は自分の過去の種目でメニューが組まれるので、
  型を選び直した既存ユーザーのメニューが定番に置き換わらないように。reviewer 指摘)。定番が入った Day では、記録中に足した種目が
  「Dayにも登録しました」の知らせとともに登録されるようになる(カスタム分割と同じ動き)
- **部位は8つのまとまり(胸・背中・肩・腕・脚・お尻・お腹・全身)で見せる**(`MUSCLE_GROUPS`、`src/domain/dayPlan.js`)。
  表示のまとめ方だけで、保存する部位名(`MUSCLES`)・集計・Watch は変わらない。お尻(臀部)だけ Day 名の `DAY_GROUP_OF` と違って脚から分けた
  - 記録タブの種目ピッカー(下の一覧・カードの間に挿入するパネル)は折り返して全部見せる。`pickerMuscle` には部位名ではなく**まとまりの id** が入る。
    まとまりで絞ったら、240px の枠をやめて画面ごとスクロールし、細かい部位(三角筋前部…)の見出しで区切る。右の札は器具だけ。内蔵種目の無い「全身」は出さない
  - 分割タブの Day 編集は、まとまりを押すと中の部位を全部足す/外す。肩・腕など中が分かれるまとまりは、選ぶと下に細かい部位のチップが出て1つずつ外せる
    (一部だけ入っているまとまりは白枠)。部位の `<select>` は optgroup で区切った
- 関数名の注意: index.html の App の中に `muscleGroupOf`(見出し用、別物)があるので、dayPlan.js 側は `groupOfMuscle` にした(同じ名前にしたら App の中で隠れて、全部の部位が「まとまりに無い」扱いになった)
