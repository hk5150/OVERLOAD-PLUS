# 毎晩のストーリー(リンクのスタンプ)の手順

2026-10-15 作成。リールを見た人を App Store に送る入口を、プロフィールのリンクのほかにもう1つ作る。
週の計画(`weekly-plan-2026-10-14.md` の「毎日のストーリー」)の手作業の部分を、iPhone で迷わないように1枚にしたもの。

**なぜ手作業か**: Instagram の API はストーリーを出せても、リンクのスタンプを付けられない。リンクの無いストーリーでは目的を果たさないので、自動にはしない。

## きっかけ

JP のリールは毎日 20:30 に自動で出て、毎回 @hajimek_workout にコラボの招待が届く。
**招待の通知が iPhone に来たら、承認のついでにこの手順をする**(新しい通知の仕組みは足していない)。当日に出せなければ翌朝でよい。

## 最初に1回だけ: リンクを単語登録する

設定 → 一般 → キーボード → ユーザ辞書 → ＋

- 単語: `https://apps.apple.com/app/apple-store/id6816090624?pt=129352960&ct=instagram_story&mt=8`
- よみ: `すとーりー`

以後、スタンプの URL 欄で「すとーりー」と打てば候補に出る。
プロフィールのリンク(`ct=instagram`)とは別の値なので、ストーリー経由だけを分けて数えられる。

## 毎晩(1分)

1. @kurabell_workout_log_jp で今日のリールを開く → 紙飛行機 → 「ストーリーズに追加」
2. 上のスタンプのボタン → 「リンク」 → URL に「すとーりー」(単語登録したもの)
3. 「スタンプのテキストをカスタマイズ」に `アプリを見る` → 完了
4. スタンプをリールの下(画面の下3分の1、文字に重ならない所)に置く → 「ストーリーズ」で出す

## 最初に1回だけ: ハイライト「アプリ」

1回目のストーリーを出した後、そのストーリーを「ハイライト」に追加し、名前を `アプリ` にする。
ストーリーは24時間で消えるが、ハイライトに入れたものはリンクごとプロフィールに残る。
2回目以降は足さなくてよい(リールの紹介で埋まると、プロフィールに来た人がリンクに届きにくくなる)。

## EN

今はやらない。EN の平均視聴は2〜3秒(JP は4.6〜8.9秒)で、App Store の表示も88%が日本。
やるときは `ct=instagram_story_en` にする(EN のプロフィールの `ct=instagram_en` とは分ける)。

## 数字の見方

- タップ数: Instagram のストーリーのインサイト(出してから24時間後に、アーカイブから「リンクのタップ」)
- App Store: App Store Connect の分析 → キャンペーン → `instagram_story`。**5人以上になるまで表示されない**
- 判定は施策ボードの P021(Obsidian `Projects/kurabell-pdca.md`)
