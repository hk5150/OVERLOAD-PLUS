## TikTok と違うところ

1. **検索から長く見られる。** TikTok は投稿日にほぼ全部が来て翌日から 0 に近い(01・02 で確認)。
   YouTube のショートは YouTube 検索・Google の検索結果にも出るので、後から見られる余地がある(一般に言われていることで、このアカウントではまだ確かめていない)。
   - タイトルは検索される言い方を前に置き、動画の問いかけを後ろに置く。例: 「筋トレ 軽い重さでも筋肉はつく?|研究で確かめた」
   - 動画の中身(思い込みをひっくり返す問いかけで始める)は変えない
2. **ショートの説明欄のリンクは押せない。** チャンネルのリンク欄は押せるので、そこにキャンペーンリンクを置く。
   説明欄の締めは TikTok と同じ「App Storeで「KURABELL」と検索」
   ```
   https://apps.apple.com/app/apple-store/id6816090624?pt=129352960&ct=youtube&mt=8
   ```
3. **見る数字。** YouTube Studio の「スワイプされずに視聴」の割合が、TikTok の 2秒継続率(03 で 34%)に当たる。
   投稿の約24時間後に、これと平均視聴率・視聴回数を控える
4. **AI のラベル。** アップロード時の「改変または合成されたコンテンツ」を「はい」にする(写真が写実的な AI 生成、ナレーションも AI)
5. **投稿は YouTube Studio の予約投稿で自動にする**(2026-10-17 北村さん「毎日自動投稿して」)。YouTube Data API でのアップロードは、Google の監査を通していないプロジェクトだと非公開にしかならないので使わない。
   チャンネルの作成は北村さんが行った(Claude はアカウントを作らない)

## 毎日の予約投稿(13時のルーティンが行う)

2026-10-17 北村さんの依頼。新しい TikTok 版の動画ができたら、同じ日のうちに YouTube Studio に上げて予約する。

1. 動画は iCloud Drive `KURABELL-TikTok/NN-題.mp4`、キャプションは同じ名前の `.txt`
2. タイトル・説明文を `drafts/` に書く(タイトルは検索される言い方を前に、説明文は TikTok のキャプションから「保存」「コメント」の呼びかけを除き、末尾を「App Storeで「KURABELL」と検索(チャンネルのリンクからも開けます)」、ハッシュタグの先頭に `#Shorts`)
3. Mac の Chrome で YouTube Studio(チャンネル @kurabell_workout_log_jp に切り替えてから)を開き、動画を上げる。
   ファイル選択の画面は Claude in Chrome から操作できないので、ページの `input[type=file]` に JavaScript で `File` を渡す
   (`fetch` で取れる URL に動画を置く。プロフィール写真とバナーはこの方法で入れた)
4. 設定: 子ども向けではない / 「改変または合成されたコンテンツ」=はい / 公開は「スケジュールを設定」で、TikTok と同じ日の 12:30
5. `published/` に、YouTube の URL と公開日時を書く

2026-10-18 に 03〜12 をこの手順で予約した(`published/2026-10-18-03-12.md`)。そのとき分かったこと:

- 動画は Mac の `127.0.0.1:8800` から配る。CORS と `Access-Control-Allow-Private-Network: true` を返す小さな Python サーバを
  `KURABELL-TikTok/` で動かす。Chrome は初回だけ「ローカルネットワークへのアクセス」の許可を聞く
- アップロード画面は `…/videos/upload?d=ud` を開けば出る。`input[type=file]`(`ytcp-uploads-dialog` の中)に `File` を渡す
- タイトルと説明文は `#textbox[contenteditable]` の1つ目と2つ目に `execCommand('insertText')` で入る。ラジオボタンは `name` で選べる
  (`VIDEO_MADE_FOR_KIDS_NOT_MFK`、「さらに表示」を開いてから `VIDEO_HAS_ALTERED_CONTENT_YES`)
- 「次へ」と「スケジュールを設定」は画面上で押す。時刻欄は文字を打っても入らないので、開いた一覧から `12:30` を選ぶ
- 終わったら「ショート」の一覧で、全本が「公開予約」と予定日になっているかを見る

予約は YouTube 側で動くので、Mac が止まっていても予約済みの分は出る。ストックが切れたら、TikTok と同じく新しい動画を作るまで止まる。
