# ストーリーズ「回数+1も前進？」3D 版(15秒・縦型・JP)

2026-11-08、北村さんの依頼「参考動画であげたように3dで目を引く形で一度お願い」(参考: X @0xnicc0 の立方体マスコットの動画)。
中身は 2D 版(`../2026-11-08-story-reps/`)と同じで、見せ方を 1100 個の立方体の 3D にした。

| | |
|---|---|
| 流れ | 空から立方体が落ちてバーベルが組み上がる(掴み)→ 崩れて2本の塔(重さ↑ +21.8kg / 回数↑ +19.3kg)→ 1段=1回の階段(8・9・10段、増えた段は緑)→ 輪になって実物の記録画面のまわりを回る → はじけて締め |
| 根拠 | Plotkin D et al. PeerJ 2022。塔の数字はスクワット1RMの伸び(`instagram/drafts/2026-10-07-po-reel.md` で Table 1 から確認済み、2026-10-06)。塔の高さは 20段:18段で比に合わせた |
| 素材 | `rows.png`(`instagram/assets/hero-ja.png` の切り出し)、`icon-512.png` |
| 描き方 | three.js r149(`tools/vendor/three.min.js`、MIT、外部URLなし)。seek(t) の中だけで描く。乱数は種固定 |
| 書き出し | クラウドの Linux(SwiftShader)で約2分。日本語は `fonts-noto-cjk` を入れて Noto Sans CJK JP |

## ストーリーズ用の配慮(2D 版と同じ)
- 上 260px・下 280px に大事なものを置かない。締めの「アプリはこのリンクから ↓」の下をリンクのスタンプ用に空ける
- 右下のロゴは台の縁に重なるので、暗い下地を敷いた
