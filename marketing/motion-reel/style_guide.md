# KURABELL リールのスタイルガイド

毎回のリールはこのガイドに従う。変えたいときはここを直す(リールごとに書き換えない)。

## 描き方の約束(守らないと作り直しになる)

- `window.seek(t)` が t 秒目の画面を描くだけ。どの秒を単独で描いても同じ絵になること
- CSS の transition / animation、setTimeout、requestAnimationFrame は使わない。乱数は種を固定したものだけ(`Math.random` 禁止)
- 動きは閉形式のバネ(`spring(u, w, z)`)で付ける。等速・ただのイーズは使わない。値が何度も変わるものは、変わるたびにバネを足す(やり直さない)
- 1080×1920・30fps で描く。拡大縮小して書き出さない

## 見た目

- 色: 背景 `#141517` / 文字 `#F2F0EB` / 補助 `#A3A8B0` / 強調 黄 `#E8B33C` / 伸び 緑 `#4CAF6E` / ブランド 赤 `#E2453C`
- 書体: 数字とロゴは Barlow Condensed 800(`fonts/`)。日本語は Hiragino Sans の太字(見出し 900、補足 700)
- 1本の要素(棒・枠など)が形を変えて場面をつなぐ。場面ごとに別の飾りを足さない
- 新しいものが画面に出る間隔は 2〜4秒。何も起きない拍を作らない
- 置き場所: 文字は左 84px から。上 250px・下 420px・右端 140px(リールの UI とボタン列)には大事なものを置かない
- 右下に「KURABELL ワークアウトログ」のロゴ(締めの場面では消す)

## 使わない定番(どのリールも同じに見える原因)

- グラデーション背景の中央タイトル
- 全部の要素が同じフェードインで出る
- 四隅のラベル、意味のない粒子・光・ズーム

## 中身の約束(`../instagram/README.md`・`../x/README.md` と同じ)

- アプリにない機能・画面・数字を作らない。画面は `instagram/assets/` などの実物のスクショだけ。足りなければ作らずに北村さんに頼む
- 価格を書かない。否定形から書き出さない。最後は「プロフィールのリンクから」
- 1場面目(=カバー)は「はい/いいえ」で答えられる問いかけ。結論の場面をカバーにしない
- 1場面目に人を写さない(器具・数字・画面だけ。`instagram/analysis-2026-10-26.md`)

## 音

- 映像と同じ時計で鳴らす。場面転換=ヒュッ、小さな要素=クリック、数字が決まる瞬間=鐘
- 曲を使うときは先に拍を測り(librosa で bpm・拍・強拍を `beats.json` に)、場面の切り替えを強拍に合わせる
- 仕上がりは -14 LUFS(`tools/build.sh` が揃える)
- 目を閉じて聞いて、場面の区切りが分からなければ音作りは未完成
