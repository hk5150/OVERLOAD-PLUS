# TikTok 運用

2026-10-11 開始を決定。日本語のみ、日本の筋トレ層向け。アカウント設定は `profile.md`。

## 流れ

`drafts/` → `approved/` → `published/` のディレクトリ移動で状態を表す(`../x/`・`../instagram/` と同じ)。

1. Claude が `drafts/` に下書きを書く(1投稿 = `YYYY-MM-DD-topic.md`。動画はファイルの場所を書く)
2. 北村さんが見て良ければ `approved/` へ移す
3. **投稿は北村さんが iPhone の TikTok アプリで行う。** API(Content Posting API)はアプリの審査が要るので使わない。
   Claude はアカウントの作成・ログイン・投稿をしない
4. 投稿したら `published/` へ移し、md の末尾に投稿日時と URL を書く

投稿の確認は、Mac の Chrome(@kurabell_workout_log_jp でログイン済み)で TikTok Studio の「投稿」
(`tiktok.com/tiktokstudio/content`)を開いて読むだけでよい。投稿日時・公開範囲・視聴数・いいね・コメントが並ぶ。
curl では WAF の確認画面で止まる(2026-10-16)。投稿日時は動画 ID からも分かる(上位32ビットが Unix 秒)。

## 動画

Instagram のリールと同じ 1080×1920(9:16)をそのまま使う。新しく作らない。

- 既存: `~/Desktop/KURABELL-reels/with-theme/ja-*.mp4`
- 新しいリールは Instagram 用に作られたものを流用する(2026-10-11 からナレーション版・40〜60秒。P017)
- **iPhone から選べるように、動画とキャプションを iCloud Drive の `KURABELL-TikTok/` に置く**(番号順に投稿する。2026-10-13 に 01〜03 を置いた)
- 画面下の約 1/5 と右端は TikTok のキャプション・ボタンが重なる。大事な文字がそこにあるリールは避けるか、場面を詰め直す
- **TikTok は縦長の iPhone で画面いっぱいに映すので、左右が約1割ずつ切れる。** Instagram 用のリールをそのまま出すと端の文字が切れる(2026-10-13)。
  必ず `marketing/tools/tiktok-safe.sh <元> <出力>` で余白を付けた版を作ってから `KURABELL-TikTok/` に置く
- 音はテーマソング(自作)のまま。他人の音源は使わない

## 書くときの約束

`../x/README.md` と同じ(アプリにない機能を書かない・価格を書かない・否定形から書き出さない)。加えて:

- **「プロフィールのリンクから」とは書かない。** 個人アカウントはフォロワー1,000人までプロフィールにリンクを貼れない。キャプションの最後と動画の最後の場面に「App Storeで「KURABELL」と検索」を入れる(2026-10-15 北村さん。02〜04 は差し替え済み、元は iCloud Drive の `KURABELL-TikTok/変更前/2026-10-15/`)
  - Instagram 用のリールを流用するときは、最後の場面(参考文献とロゴ、最後の3秒)の画像に一文を足してから差し替える。作り方は `marketing/tools/tiktok-cta.sh`
- ハッシュタグは3〜5個(`#筋トレ` `#筋トレ記録` `#筋トレ初心者` `#ジム` など)
- AI 生成の写実的な画像・音声を含む動画には、投稿時に「AI生成コンテンツ」のラベルを付ける(TikTok のルール)

## 他の SNS との分担
