# TikTok 運用

2026-10-11 開始を決定。日本語のみ、日本の筋トレ層向け。アカウント設定は `profile.md`。

## 流れ

`drafts/` → `approved/` → `published/` のディレクトリ移動で状態を表す(`../x/`・`../instagram/` と同じ)。

1. Claude が `drafts/` に下書きを書く(1投稿 = `YYYY-MM-DD-topic.md`。動画はファイルの場所を書く)
2. 北村さんが見て良ければ `approved/` へ移す
3. **投稿は北村さんが iPhone の TikTok アプリで行う。** API(Content Posting API)はアプリの審査が要るので使わない。
   Claude はアカウントの作成・ログイン・投稿をしない
4. 投稿したら `published/` へ移し、md の末尾に投稿日時と URL を書く

投稿の確認は、Mac の Chrome(@kurabell_workout_log_jp でログイン済み)で TikTok Studio の「投稿」
(`tiktok.com/tiktokstudio/content`)を開いて読むだけでよい。投稿日時・公開範囲・視聴数・いいね・コメントが並ぶ。
curl では WAF の確認画面で止まる(2026-10-16)。投稿日時は動画 ID からも分かる(上位32ビットが Unix 秒)。

## 数字の取り方

毎日 11:50 に launchd(`com.kurabell.tiktok-stats`、`marketing/tools/com.kurabell.tiktok-stats.plist`)が
`marketing/tools/tiktok-stats.py` を動かし、投稿ごとの再生・いいね・コメント・シェア・保存とフォロワー数を
`reports/tiktok/tiktok-stats.csv`(履歴)と `.md`(最新の表と直近14日の推移)に残す。12時のルーティンが読んで報告に載せる。
ログは `reports/tiktok/launchd.log`。

- 新しい投稿は、`published/*.md` に URL(`https://www.tiktok.com/@kurabell_workout_log_jp/video/…`)を書けば翌日から拾われる
- 止めるとき: `launchctl bootout gui/$(id -u)/com.kurabell.tiktok-stats`

## 台本の型(2026-10-17)

コンセプトは他の SNS と同じ「**エビデンスをもとに有益な情報を提供する**」。研究で答える問いかけ → 「KURABELLなら」で機能を1つ。
クイズ・小ネタ・機能だけの動画は作らない(10/15 北村さん)。
2026-10-17 に北村さんが共有した X の投稿(@fukuzawa_afi、Claude Code で TikTok を回す手順)から、このコンセプトに合う所だけを取り入れた。

- **1本を「冒頭2秒 / 本編 / 最後の一言」に分けて書く。** 冒頭2秒は、**「〜でも、〇〇?」の朗報の問いかけ**(03「軽い重さでも、筋肉はつく?」の形。答えが「はい」なら見た人が得をする問い)。「あなたのやり方、間違ってない?」という注意の形や、やり方を聞く形は伸びなかった(04・05、Instagram の「どうやって決めていますか?」。`review-2026-10-17.md`)。答えは研究の範囲で「はい」と言えるものだけ。最初の場面は4秒以内、1場面5〜6秒、全体30〜35秒
- **結論ははっきり言い切る**(2026-10-27 北村さん「動画は結論、はっきりさしたほうがいい」)。最後の一言の場面を「結論」にして、冒頭の問いに冒頭と同じ言葉で答える(例: 「結論: 週1回でも、筋肉はつく。」)。条件は1つまで。「〜かも」「続けやすい方で」のような答えをぼかす締めや、答えの代わりのアドバイスで終わらない。研究の範囲で言い切れない題材は、そもそも冒頭の問いを言い切れる形に変える
- **結論の言い方は毎回変える**(同じ締めの繰り返しを避ける)。動画の最後の場面の「App Storeで「KURABELL」と検索」は固定のまま、その前の結論を変える
- **同じ言い回しは、直近の台本で2回まで**(「〜していませんか?」の連続など)
- **「保存」を狙う回と「共感」を狙う回を半々にする。** 保存の回は数字や目安を持ち帰れる研究(例: 05〜07)。共感の回は、筋トレのよくある悩み(伸び悩み・続かない・時間がない)に研究で答える回。どちらも研究の数値は原典(抄録か本文の表)で確かめたものだけ
- **台本はまとめて作り置きする**(5〜10本ずつ)。ただし研究の確認が要るので、確かめ終えたものから `drafts/` に入れる。数を優先して確認を飛ばさない
- **ナレーションは読み上げ用に直してから録る**: 数字は読み仮名(「42〜57%」→「よんじゅうに から ごじゅうなな パーセント」)、1文は短く切る、息継ぎで改行、字幕は1行13文字以内

## 分析の回し方(2026-10-17)

- 投稿の約24時間後に、TikTok Studio の 2秒・3秒の継続率、平均視聴時間、保存数を `published/` の md に書く(`analysis-2026-10-16.md` の表と同じ項目)
- **動画を作るとき・出す前に、毎回中身を見直す**(北村さんの常設の依頼、2026-10-17): 冒頭2秒・題材の広さ・最後の一言・検索の案内。直した点は `review-YYYY-MM-DD.md` に残す
- **5本たまるごとに、伸びた回と伸びなかった回の冒頭2秒の違いを3つまでにまとめ、次の台本の条件をその3つで書き直す。** 感覚ではなく、継続率の数字で比べる
- **次の台本の8割は、いちばん伸びた型に寄せ、2割で新しい型を試す。** 1本ごとに変える条件は1つにする(何が効いたか読めるように)
- 取り入れなかったもの: 売るものを後から決める・公式LINE への導線(アプリが売るものなので当てはまらない。個人アカウントはフォロワー1,000人までプロフィールにリンクも貼れない)、毎日2本(投稿は北村さんの手作業なので、増やすかは北村さんが決める)

## 書くときの約束

`../x/README.md` と同じ(アプリにない機能を書かない・価格を書かない・否定形から書き出さない)。加えて:

- **「プロフィールのリンクから」とは書かない。** 個人アカウントはフォロワー1,000人までプロフィールにリンクを貼れない。キャプションの最後と動画の最後の場面に「App Storeで「KURABELL」と検索」を入れる(2026-10-15 北村さん。02〜04 は差し替え済み、元は iCloud Drive の `KURABELL-TikTok/変更前/2026-10-15/`)
  - Instagram 用のリールを流用するときは、最後の場面(参考文献とロゴ、最後の3秒)の画像に一文を足してから差し替える。作り方は `marketing/tools/tiktok-cta.sh`
- ハッシュタグは3〜5個(`#筋トレ` `#筋トレ記録` `#筋トレ初心者` `#ジム` など)
- AI 生成の写実的な画像・音声を含む動画には、投稿時に「AI生成コンテンツ」のラベルを付ける(TikTok のルール)
