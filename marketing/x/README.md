# X(旧Twitter)運用

2026-10-04 開始。日本語のみ、日本の筋トレ層向け。

## 流れ(2026-10-11 から)

1. Claude が `drafts/` に下書きを書く(1投稿1ファイル、番号が投稿の順)
2. **Claude が X の下書き(Web の投稿画面 → 閉じる → 保存)に、本文と画像を入れる**。
   Web で保存した下書きは iPhone の X アプリにも出る(北村さんが確認済み)
3. **投稿は北村さんが X アプリから行う。** Claude は投稿しない。予約投稿も使わない
4. 投稿されたら、Claude が URL を拾って `published/` へ移す

### Chrome で X を操作するときの注意(実際に踏んだ)

- **投稿画面が開いたことを確かめずに文字を打たない。** X は英字1文字のキーがショートカットで、
  本文の英字で「いいね」「フォロー」が勝手に起きた。入力欄にフォーカスがあることを JS で確かめてから打つ
- **座標で押さない。** ウィンドウの大きさが変わると押す位置がずれ、予約が確定してしまった。
  要素を探して(find / ref)押す。X のダイアログは要素の一覧に出ないことがあるので、
  JS でダイアログ内の file input と閉じるボタンに目印の aria-label を付けてから find で拾う
- 北村さんの Chrome は X のページに自動翻訳がかかり、表示の文字が化ける(保存された中身は正しい)

## リンク

App Store へのリンクは必ず X 用のキャンペーンリンクを使う(素のURLだと流入元が数えられない)。

```
https://apps.apple.com/app/apple-store/id6816090624?pt=129352960&ct=x&mt=8
```

数字は App Store Connect「アナリティクス → 獲得 → キャンペーン」の `x`。5人以上入るまで表示されない。
日次ルーティンが `Projects/kurabell-metrics.md`(Obsidian)に記録している。

## 書くときの約束

- **アプリにない機能を書かない。** 文言は `src/domain/i18n.js` の実際の表示と照らす。App Store の掲載文と同じく、
  「次の重量を自動で決める」とは書かない(判断はユーザーに委ねるアプリ)
- **価格を書かない。** 「最初の10回は全機能無料、あとは一度の購入でずっと」までにとどめる
- **否定形から書き出さない。** 「サブスクなし」は売りだが、冒頭は得られるものから(`APPSTORE.md` の掲載方針と同じ)
- 画像はアプリの実際の画面を使う。Instagram 用に作った素材(`~/Desktop/KURABELL-instagram-story/v3/`)は流用してよい
- ハッシュタグは1〜2個まで(`#筋トレ` `#筋トレ記録` など)

## Instagram との分担

Instagram は「アプリのマーケティング戦略」セッションが担当。X の下書きはこのディレクトリ。
同じ素材を使うときは、文面は X 向けに短く書き直す。
