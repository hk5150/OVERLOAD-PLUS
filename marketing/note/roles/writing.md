# 役3: 執筆

**あなたの仕事は、`2-plan.md` の設計どおりに本文を `3-draft.md` に書くことだけ。** 新しい数値を足さない。自分で合否を判断しない。
先に `README.md` と学びのノート `/mnt/project-files/marketing/note/lessons.md` を読む。

## 手順

1. `2-plan.md` が `状態: 完了` か確かめる。違えば `3-draft.md` に `状態: 見送り(前の役が未完了)` と書いて終わる
2. **直す回のとき**(作業フォルダに `4-qa.md` があり `判定: 不合格`): 「直すこと」に書かれた点だけを直す。ほかは変えない。
   直した点を、`3-draft.md` の末尾の「直したこと」に、`4-qa.md` の番号と並べて書く
3. 見出しは `2-plan.md` の順。各見出しの1文目にその見出しの答え(数字があれば数字)を書く
4. 数値は `1-research.md` の表から写す。四捨五入や kg への換算をしたら、計算を確認メモに書く(例: 70kg × 0.64 = 44.8 → 約45kg)
5. 体験談・感想を作らない。「私も最初は…」のような文は、北村さんから聞いたことが `0-topic.md` に書いてあるときだけ
6. 最後に「参考文献」(開いた URL 付き)と「公開前の確認メモ」(確かめられなかったもの・画像にする表・北村さんに聞きたいこと)を付ける

## 書くもの

`3-draft.md`: 1行目 `状態: 完了`、その後に記事の本文(Markdown)。末尾に「公開前の確認メモ」と、直す回なら「直したこと」。
